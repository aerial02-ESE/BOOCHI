# BOOCHI · 88+25 可视化演奏平台

BOOCHI 是一套基于高云 GW5AT-60B FPGA 的可视化演奏平台与离线辅助演奏系统。作品将 88 键主奏键盘、25 键交互控制器、实时声音合成、屏幕显示和键盘灯光结合起来，并通过 Android App 提供音色调节与曲谱管理，让同一套设备同时服务于演奏和日常练习。

88 键键盘承担主旋律与和声演奏，SMK25 提供便携键盘、Pad 和触摸交互。演奏输入交由 FPGA 实时处理，力度、弯音、调制和延音等控制随演奏作用于声音，屏幕与灯光同步呈现演奏信息。

## 主要功能

- **双键盘演奏**：结合 88 键与 25 键输入，支持多维表情控制和键盘分区音色设置。
- **多音色合成**：提供钢琴、管风琴、鼓组、长笛、小提琴等 11 种音色，支持 32 声部复音。
- **硬件音效**：在 FPGA 内完成合唱、混响和延迟处理，可通过 App 调节音量、效果量及包络参数。
- **演奏可视化**：通过屏幕展示频谱、键盘状态和立体声李萨如图形，配合 88 键灯光反馈呈现演奏过程。
- **离线辅助练习**：曲谱保存到设备后可独立运行，提供灯光跟弹提示、演奏判定和成绩反馈。
- **手机交互**：Android App 通过蓝牙连接设备，支持虚拟琴键、音色与效果控制、MIDI 曲谱导入及演奏事件记录回放。

## 系统组成

FPGA 是整套作品的实时处理核心，负责声音合成、音效与视听反馈；ESP32 承担通信桥接和曲谱存储；Android App 提供演奏控制与练习管理界面。三者共同构成从演奏输入到声音、画面和灯光输出的完整系统。
